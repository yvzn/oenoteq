# UI vocabulary (EN / FR)

Approved display labels for the localized UI (ADR 0011). These are UI labels, not domain terms: `CONTEXT.md` keeps the canonical French terms for code and discussion, and stored values (`rouge`, `blanc`, `rose`, Garde Status codes) never change.

| Concept | EN label | FR label |
|---|---|---|
| Cellar | Cellar | Cave |
| Wine | Wine | Vin |
| Millesime | Vintage | Millésime |
| Garde (window) | Drinking window | Fenêtre de garde |
| Garde start / end | Start / End | Début / Fin |
| Garde Status `too_young` | Too young | Trop jeune |
| Garde Status `ready` | Ready | À boire |
| Garde Status `past_peak` | Past peak | Passé |
| Garde Status `unassessed` | Not assessed | Non évalué |
| Appellation | Appellation | Appellation |
| Producer | Producer | Producteur |
| Color `rouge` / `blanc` / `rose` | Red / White / Rosé | Rouge / Blanc / Rosé |
| Meal | Meal | Plat |
| Meal Pairing | Meal pairing | Accord mets-vin |
| Quantity | Quantity | Quantité |
| Consumption | Consumption | Consommation |

Not translated: user data (wine, producer, meal and appellation names, consumption notes), the PWA manifest name, server error codes.
